# CryptoTerminal — Mr Ragnar

## Запуск
1. Распакуй архив.
2. Открой `index.html` в браузере для локального просмотра.
3. Для публикации создай репозиторий GitHub и загрузи `index.html` и `ragnar-hero.jpg` в корень.
4. В GitHub открой Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Функции
- Анимированный арт с медленным движением, красным свечением и частицами.
- Ручное добавление/редактирование/удаление активов.
- Расчёт стоимости, доли и P/L при указанной цене покупки.
- Ручное сохранение снимков истории и график по снимкам.
- CSV-экспорт, имя профиля и демонстрационный режим.
- Данные сохраняются локально в браузере; никаких приватных ключей не требуется.

Примечание: в этом стартовом варианте герой анимируется CSS-эффектами и частицами поверх изображения. Реалистичное движение отдельных частей тела потребует подготовленных отдельных слоёв или видео.
